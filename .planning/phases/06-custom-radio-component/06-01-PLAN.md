  <name>Task 1: Create reusable RadioGroup component with styling props</name>
  <files>packages/sveltekit/src/lib/components/RadioGroup.svelte</files>
  <action>
Create a new Svelte 5 component at `packages/sveltekit/src/lib/components/RadioGroup.svelte`.

**Props interface** (using `$props` rune):
- `options`: Array of `{ value: string; label: string }` — the radio options to render
- `value`: `string` — currently selected value (controlled component)
- `name`: `string` — the radio group name attribute for form semantics
- `onchange`: `(value: string) => void` — callback when selection changes
- `color`: `string` (optional, default `'currentColor'`) — fill color of the active radio indicator
- `size`: `number` (optional, default `12`) — diameter in pixels of the radio indicator circle/shape
- `shape`: `'circle' | 'square'` (optional, default `'circle'`) — shape of the indicator

**Implementation approach:**
- Use a `<div role="radiogroup">` as container
- Each option is a `<label>` containing:
  - A visually hidden native `<input type="radio">` (for accessibility — `position: absolute; width: 1px; height: 1px; overflow: hidden; clip: rect(0,0,0,0)`)
  - A styled `<span class="radio-indicator">` that visually represents the radio state
  - A `<span class="radio-label">` with the text label
- The indicator span renders as a bordered outline when unselected, filled with `color` prop when selected
- When `shape` is `'circle'`, use `border-radius: 50%`. When `'square'`, use `border-radius: 2px`
- Size is controlled by the `size` prop applied as `width` and `height` on the indicator span via inline style
- Use CSS variables from the project theme: `var(--foreground)` for the indicator border, `var(--archive-border-color)` as fallback

**Keyboard behavior:** Native radio inputs handle arrow key navigation automatically since they share the same `name` attribute.

**Styling conventions:** Follow project conventions — `<style lang="scss">`, BEM-like class names prefixed with `radio-` (e.g., `.radio-group`, `.radio-option`, `.radio-indicator`, `.radio-label`), scoped styles.

**Do NOT add animations or transitions** (explicitly out of scope per REQUIREMENTS.md).
