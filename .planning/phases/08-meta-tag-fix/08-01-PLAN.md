<objective>
Fix archive page OG/meta tags so crawlers pick up collection-specific metadata instead of the main page values.

Purpose: When sharing an archive collection URL on social media, the preview currently shows "World Affairs AB" (the main page title) instead of the collection's own title and description. This is because `app.html` has hardcoded OG meta tags that appear before the `%sveltekit.head%` injection point, causing crawlers to pick up the first (main page) values and ignore the archive page's `<svelte:head>` values.

Output: `app.html` stripped of all OG/description meta tags; home page `+page.svelte` owns its own OG tags via `<svelte:head>`; archive pages no longer compete with hardcoded tags.
</objective>

**Root cause:** `app.html` has hardcoded OG meta tags (og:title, og:description, og:type, og:url, og:image, twitter:card, twitter:title, twitter:description, twitter:image:src) plus a `name="description"` tag and a `<title>` tag. These appear BEFORE `%sveltekit.head%`, so crawlers see the main page values first, ignoring archive-specific `<svelte:head>` values.

**In `packages/sveltekit/src/app.html`:**

Remove these lines (keep everything else — charset, favicon, preload, viewport, stylesheet, theme-color, sveltekit.head):
- Line 9: `<title>World Affairs AB</title>`
- Line 10: `<meta property="og:title" content="World Affairs AB" />`
- Lines 11-14: `<meta name="description" ...>`
- Lines 15-18: `<meta property="og:description" ...>`
- Line 19: `<meta property="og:type" content="website" />`
- Line 20: `<meta property="og:url" content="https://worldaffairs.se/" />`
- Line 21: `<meta property="og:image" content="https://worldaffairs.se/images/og.jpg" />`
- Line 23: `<meta name="twitter:card" content="summary_large_image" />`
- Line 24: `<meta name="twitter:title" content="World Affairs AB" />`
- Lines 25-28: `<meta name="twitter:description" ...>`
- Line 29: `<meta name="twitter:image:src" content="https://worldaffairs.se/images/og.jpg" />`

Keep only:
```html
<meta charset="utf-8" />
<link rel="icon" href="%sveltekit.assets%/favicon.png" />
<link rel="preload" href="%sveltekit.assets%/images/wa-logo-alt.png" as="image" />
<meta name="viewport" content="width=device-width, initial-scale=1" />
<link rel="stylesheet" href="%sveltekit.assets%/app.css" />
<meta name="theme-color" content="#d0d0d0" />
%sveltekit.head%
```

**In `packages/sveltekit/src/routes/+page.svelte`:**

Replace the existing `<svelte:head>` block (currently only `<title>World Affairs AB</title>`) with a complete set of meta tags. Add ALL the tags that were removed from `app.html`:

```svelte
    <meta property="og:image" content="https://worldaffairs.se/images/og.jpg" />

    <meta name="twitter:description" content="World Affairs is a record label founded in 2020 by Yung Lean, based in Stockholm, Sweden." />
    <meta name="twitter:image:src" content="https://worldaffairs.se/images/og.jpg" />
</svelte:head>
```

**Do NOT modify** `packages/sveltekit/src/routes/archive/[slug]/+page.svelte` — its existing `<svelte:head>` tags are correct and will now be the ONLY OG tags in the HTML for archive pages.
