  <action>
Edit `packages/sanity/schemaTypes/Work.ts` to add three new fields:

**A. Add `credits` and `year` to each media object type (imageMedia, audioMedia, videoMedia):**

After the existing `caption` field in each of the three media object `fields` arrays, add:

```typescript
{
    title: 'Credits',
    name: 'credits',
    type: 'text',
    rows: 3,
},
{
    title: 'Year',
    name: 'year',
    type: 'number',
    validation: (Rule: any) => Rule.integer().min(1900).max(2100),
},
```

This must be added to all three media types: `imageMedia` (line ~72-87), `audioMedia` (line ~105-120), and `videoMedia` (line ~136-151). Place the new fields after the `caption` field in each object's `fields` array.

Do NOT add these to the document root fields — there is already a root-level `credits` field (line ~58-62). The new per-media credits is intentionally a separate field scoped to each media item.

`year` is optional (no `Rule.required()`) — existing media items should not fail validation. `credits` is also optional (text type, no validation needed).

**B. Add `defaultView` radio field to document root:**

Add a new field to the document root `fields` array (after the existing `credits` field at line ~58-62, before the `media` array field). Insert:

```typescript
{
    title: 'Default View',
    name: 'defaultView',
    type: 'string',
    options: {
        list: [
            { title: 'Image', value: 'image' },
            { title: 'Text', value: 'text' },
            { title: 'Grid', value: 'grid' },
        ],
        layout: 'radio',
        direction: 'horizontal',
    },
    initialValue: 'image',
},
```

Both `layout: 'radio'` and `direction: 'horizontal'` must be set together. `initialValue: 'image'` sets the default for newly created documents only (existing documents will have `undefined` until re-saved — this is expected and Phase 3 handles fallback).

- `credits` and `year` fields appear in all three media objects (imageMedia, audioMedia, videoMedia)

- All commas and brackets are properly balanced
