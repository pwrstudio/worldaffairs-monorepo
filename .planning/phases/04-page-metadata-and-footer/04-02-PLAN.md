Current WorkLayout structure:
```
<div class="work-layout">
    <WorkTopBar ... />
    <div class="content">
        {#if viewMode === 'slideshow' && hasMedia}
            <ImageView ... />
        {:else if viewMode === 'table' && hasMedia}
            <TableView ... />
        {:else}
            <div class="no-media">...</div>
        {/if}
    </div>
</div>
```

Make the following changes:

1. Add `lastUpdated` to the props destructure:
```typescript
const { work, lastUpdated } = $props<{
    work: Work;
    lastUpdated?: string;
}>();
```

2. Format the date for display. Add a derived value after the `yearDisplay` line:
```typescript
const formattedLastUpdated = $derived(
    lastUpdated
        ? new Date(lastUpdated).toLocaleDateString('en-GB', {
              year: 'numeric',
              month: 'long',
              day: 'numeric',
          })
        : null
);
```

3. Add a footer strip to the template, immediately after the closing `</div>` of `.content` and before the closing `</div>` of `.work-layout`:
```svelte
{#if formattedLastUpdated}
    <div class="page-footer">
        Page last updated: {formattedLastUpdated}
    </div>
{/if}
```

4. Add CSS for `.page-footer` inside the `<style lang="scss">` block (inside `.work-layout`):
```scss
.page-footer {
    flex-shrink: 0;
    padding: 0.25em 20px;
    font-size: var(--font-size-small);
    color: var(--foreground);
    border-top: 1px solid var(--archive-border-color);
    text-align: right;
}
```

The `.work-layout` uses `display: flex; flex-direction: column; height: 100dvh; overflow: hidden`. Adding `flex-shrink: 0` to `.page-footer` ensures it stays at the bottom without collapsing.

Do NOT remove the existing `<Footer />` inside `TableView.svelte` — it shows "Site last updated" for the whole site and "You are visitor number" which is separate from this work-specific last-updated footer. The two footers serve different purposes and are in different view contexts.
