<task type="auto">
  <name>Task 1: Add OG metadata and canonical link to archive detail page</name>
  <files>packages/sveltekit/src/routes/archive/[slug]/+page.svelte</files>
  <action>
The file currently has:
```svelte
<script lang="ts">
    import type { Work } from '@sanity-types';
    import WorkLayout from '$lib/components/Works/WorkLayout.svelte';

    export let data: { work: Work; };
    const { work } = data;

</script>

<svelte:head>

<title>{work.title} | World Affairs AB</title>
</svelte:head>

<WorkLayout {work} />

````

Make the following changes:

1. Add `import { urlFor } from '$lib/modules/sanity';` to the script block (after the existing imports).

2. Add derived values in the script block:
   - `const pageTitle = \`\${work.title} | World Affairs AB\`;`
   - `const pageDescription = work.intro ? work.intro.slice(0, 155) : '';` — intro is a plain string field
   - Find the first imageMedia item: `const firstImage = (work.media ?? []).find((m) => m._type === 'imageMedia');`
   - Build OG image URL: `const ogImageUrl = firstImage && firstImage._type === 'imageMedia' ? urlFor(firstImage.image).width(1200).height(630).fit('crop').url() : '';`
   - Build canonical URL: `const canonicalUrl = \`https://worldaffairs.se/archive/\${work.slug.current}\`;`

3. Replace the `<svelte:head>` block with:
```svelte
<svelte:head>
    <title>{pageTitle}</title>
    <meta name="description" content={pageDescription} />
    <link rel="canonical" href={canonicalUrl} />
    <meta property="og:type" content="website" />
    <meta property="og:title" content={pageTitle} />
    <meta property="og:description" content={pageDescription} />
    <meta property="og:url" content={canonicalUrl} />
    {#if ogImageUrl}
        <meta property="og:image" content={ogImageUrl} />
    {/if}
</svelte:head>
````

4. Also pass `lastUpdated={work._updatedAt}` to `WorkLayout`:

```svelte
<WorkLayout {work} lastUpdated={work._updatedAt} />
```

(WorkLayout will consume this prop in plan 04-02. Passing it now is safe — the prop will be silently ignored until WorkLayout is updated.)

Type note: `firstImage.image` is typed as `{ asset?: SanityImageAssetReference; ... }`. The `urlFor` builder from `@sanity/image-url` accepts this. Use type assertion `urlFor(firstImage.image as any)` if the TypeScript compiler complains about the asset reference type.

Import order: external first (`@sanity-types`), then `$lib` aliases.

This is the only change needed — SvelteKit's `<svelte:head>` is reactive per-page, so navigating to `/` will replace any title set by the archive page.
